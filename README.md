# Agenda em Desenvolvimento

Este projeto é uma Agenda em desenvolvimento. Ele contém arquivos iniciais para criar um sistema de organização e gerenciamento de compromissos.

Funcionalidades previstas:
- Listar compromissos
- Adicionar novos eventos
- Editar e excluir itens da agenda
- Notificações e atualização em tempo real

O projeto ainda está em construção e continuará evoluindo com novas funcionalidades e melhorias.
